# Architecture decision records

Numbered Markdown files record decisions that change this package’s public contract.

## Naming

`NNNN-short-title.md` — for example `0001-band-indexed-cat-fields.md`. Use the next free number when adding a record.

| Record | Status | Topic |

## Status

Each ADR has a **Status**: `proposed`, `accepted`, or `superseded`.

## Sections

Keep records short (about one page).

- **Context** — the problem or forces that led to a decision.
- **Decision** — what we chose.
- **Consequences** — trade-offs and follow-on work.

Add **Date** and **Related** (issues or external ADRs) when they help.
